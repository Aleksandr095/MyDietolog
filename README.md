# MyDietolog

Дневник питания и тренировок для Android.

**Питание:** календарь, приёмы пищи (завтрак, обед, ужин, перекус), блюда с 1–2 фото,
описанием, весом и своей оценкой калорий. Выгрузка недели в ZIP
(`diary.md`, `diary.json`, `photos/`) — в архиве питание, факты тренировок и отметки дня.

**Отметки дня:** месячные да/нет, голод и стресс по шкале 0–10. Все поля необязательные;
в выгрузке — значения по дням и средние за неделю.

**Напоминания** (экран «Настройки», шестерёнка на главном экране):
- о дневнике — одно или несколько времён в день; можно привязать к приёму пищи.
  Напоминание не приходит, если приём уже записан;
- пить воду — интервал (1–4 ч) и окно времени, ночью не беспокоит.
Напоминания переживают перезагрузку телефона. Нужно разрешение на уведомления.

**Тренировки:** вкладка с программой из JSON-файла, факт занятия (подходы вес×повторы,
кардио в минутах), упражнения вне плана, подсказки названий из кэша.
При замене программы отмеченные факты и «в прошлый раз» сохраняются.

Все данные хранятся только на телефоне. В репозитории — только код.

## Программа тренировок

Программа **не вшита** в приложение. Загрузите файл на экране
«Тренировки → Программа».

Пример: [`samples/liliya_program.json`](samples/liliya_program.json)
(сила 3× в неделю + ходьба). Скопируйте на телефон и выберите через
«Выбрать файл программы…». Откроется системное окно выбора,
отдельное разрешение на хранилище не нужно.

Формат (кратко):

```json
{
  "id": "…",
  "title": "Название",
  "sessions": [
    {
      "id": "strength-a",
      "name": "Сила A",
      "weekday": 1,
      "exercises": [
        {
          "id": "squat-db",
          "name": "Приседания с гантелями",
          "target": "3 × 10–12",
          "note": "…",
          "technique_url": "https://…",
          "kind": "strength"
        }
      ]
    }
  ]
}
```

`weekday`: 1 = понедельник … 7 = воскресенье.  
`kind`: `strength` | `cardio`.

## Как получить APK

Каждый push в `main` запускает сборку в GitHub Actions. Готовый APK появляется
в разделе **Releases** (файл `MyDietolog-1.0.N.apk`).

Установка: скачать APK на телефон → открыть → разрешить установку из этого источника.
Обновление ставится поверх старой версии, данные сохраняются.
